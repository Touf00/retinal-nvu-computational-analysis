## /TEAMRED completion and scientific limitations

**GSE174574 — computed; candidate direction screen only.** Three MCAO and three sham animals. Exact balanced permutation p has a theoretical minimum of 0.100. After upgrading PyDESeq2 to 0.5.4, all four broad-compartment Wald-model DE tables ran successfully (GitHub Actions 38325572095); model p-values can be extremely small with n=3/group and must not be treated as independent strong proof relative to exact permutations. The provisional marker-based cell type labels need independent validation. RNA fold changes do not establish PET suitability.

**GSE227651 — computed; descriptive only.** One GEO matrix per condition, no animal-level estimates of variance. Limited late-timepoint astrocyte capture.

**GSE250245 — computed; rat cross-model context only.** Six pooled severity × hemisphere matrices for an 11-rat study; rat IDs not represented as six independent replicates. Provisional broad marker annotation recovers as few as 12 endothelial nuclei in a sham hemisphere. Vascular comparisons are NOT validated. Four frozen genes (Apln, Amot, Cldn5, Flt1) are absent from released rat feature symbols, not shown absent biologically. A diagnostic file lists possible aliases but never substitutes them without authoritative mapping.

**GSE233814 — five Visium sections computed.** One control, one day1, one day3, two day7. Mixed tissue spots are not individual astrocytes/endothelium. Original author's region labels `DetailedRegionAnnoShort` have not yet been transferred from processed Seurat data. Therefore NO lesion core/penumbra claims in current output.

**GSE223744 — completed independently replicated purified endothelial RNA.** Four ipsilateral ischemia versus four **naïve** sorted CD31+ mouse endothelial samples. Fractional `expected_counts` used for per-sample log2CPM and exact n4+n4 label permutation, with BH across the prespecified 29-gene panel only. This is a true independent model cohort but **not operated-sham-controlled**, and does not establish PET binding.

**GSE286075 — completed paired astrocyte-endfoot RiboTag RNA.** Three ipsilateral-versus-contralateral animal PAIRS following 2h ischemia and 6h reperfusion. STAR unstranded read-count column and Ensembl-to-symbol map traced to the purified-endothelial experiment. Two-sided sign flips n3 cannot establish p<0.25; directional evidence only, not MAO-B protein measurement.

**GSE225948 day2 — source-audited author-annotated EC; pooled preparations only.** Four pooled Sham and four pooled tMCAO preparations; fractional expression matrices and non-matched processing batches. No BH q<.05 for any 28 tested genes either across whole EC or within EC1. EC2 is inadequately captured in Sham for valid inference. Do NOT claim individual mice n=4/group, causal expression changes, or true cell-type composition change.

**GSE225948 stroke day14 versus day2 — source-audited, no sham day14.** Four pooled stroke preparations at each timepoint; no panel-wide BH discoveries either in whole EC or within EC1. This is an unpaired disease-stage comparison, not a validated stroke-vs-sham response or causal progression.

**SCP3078 — metadata audited, full expression BLOCKED.** Public Single Cell Portal metadata expose a 5,004,976,071-byte H5AD; attempted download and stream return unauthorized response to GitHub runner. Raw expression not accessed, hence NOT analyzed. The source is an integrated atlas of partially overlapping input datasets; even with expression access, it cannot count as an independent biological replication until component study IDs are recovered.

2. Recover rat cell-type metadata or use a curated reference before declaring cross-species vascular validation; do not use the poorly captured EC group to support a PET claim.
3. Obtain the original spatial region annotation for proper core/periphery contrasts (author Seurat object / supplementary tables).
4. Investigate SCT portal large H5AD access via authorized download or validated alternative public deposit.
5. Include independent one-library **GSE337578 day3 tMCAO spatial data** (run 38325519991, archived under `results/spatial_day3/`). Coordinate mapping and gene detection are validated. The sample has no controls, so no inferential or core/peri-infarct claims.\n6. For human translation test **GSE162955** (six paired autopsy core/contralateral microarrays) with an auditable GPL17586 probe-to-gene mapping; use only whole-tissue injury evidence, not cell specificity.\n7. Perform a biological **targetability** audit for candidates: protein localization, luminal accessibility, target-to-background, binder/radiotracer availability, BBB/flow confound, human relevance.
6. Study the BBB cargo-delivery question in a separate pharmacokinetics and assay framework; no RNA-expression atlas proves productive transcytosis.

The science can reject APJ, AMOT, MAO-B or any existing tracer if independent evidence supports doing so. These are **not** automatic leading candidates.
